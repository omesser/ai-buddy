ai-buddy design pages

Pages that have to run to be judged. Everything else about the project lives in the repository, which renders it better than this can.

  • Character Gallery
    Every Character this project can publish, and all nine Required Animations, playing at the fps its own Character Manifest declares. The one thing a repository cannot show you: a walk cycle in motion.
    Generated from characters/ at deploy
  • Buddy Cues
    The visual and audio cue for each interaction — click, double-click, right-click, pickup, drop. Play each one, or try the gestures on a draggable BMO.
    Dated proposal, #277
  • Buddy Chat
    The chat surface a Summon opens: a turn in flight while the buddy keeps moving, an answer arriving as Speech and a Behavior, and the state with no Harness attached. Drive all three.
    Dated proposal, #17
  • Chat Surface, Three Ways
    One conversation in the chat surface #17 opens, drawn three ways — modern minimal, terminal log, pane of glass — so a direction can be picked. Drive all three; a switch keeps the turn that is already streaming.
    Dated proposal, #339
  • Overlay Expression
    Speech bubble reading time and the thinking ellipsis while a reactive Director turn is in flight. Type a line, Poke, reply — github.com cannot hold a bubble for you.
    Generated from src/bubble.js at deploy
