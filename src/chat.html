Nothing to answer with

ai-buddy ships no agent of its own. Point it at a Completer — a chat-completions endpoint and a key — and answers here, out of the same session that proposes what does on your desktop.

Or a Harness. An agent runtime you already run — Claude Code, Hermes, opencode — answers here instead when AI_BUDDY_HARNESS names it at launch. It signs in on its own; this window only says which command to run if it has not (ADR-0008, ADR-0010).

If you would rather not. Static weights keep moving with no model at all: the buddy still walks, reacts and speaks. This window is the only part that waits for something to answer.

Settings, on the tray menu, takes the endpoint and the key.

Answers are switched off

Settings, on the tray menu, turns the Director back on and answers here again. The buddy keeps walking and reacting either way.

Your own layer

Written for alone, and kept if you switch Characters. It follows the personality above and is bound by the same rule: it shapes how comes across on this machine. Up to characters.

Saving starts a new conversation. The Character Prompt is the opening turn, so a new one means a new session: anything still being answered is dropped, and the chat so far is gone from the model's side. What is worth keeping lives in Memory.
